Double tip and tail

Light going both ways round a ring (paper, Example 12.2). The forward and backward beams span one pair: the pair is the tail, the mode inside it is the tip. Rotation splits the two directions; scattering couples them.

Below lock-in the two directions act as one: the pattern stands still and only the pair can be read. Above it the beams run at different frequencies, the pattern slides at the beat, and each direction is a tip you can measure. Moving both mirrors together only slides the pattern; the pair holds either way.
